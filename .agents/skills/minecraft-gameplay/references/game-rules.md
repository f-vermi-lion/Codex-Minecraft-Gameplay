# ゲームルール

目標は、Minecraftの通常プレイによってエンダードラゴンを討伐することです。

- シングルプレイ
- サバイバルモード
- 難易度ノーマル
- チート、ゲーム内コマンド、LAN公開、マルチプレイを使わない
- セーブデータ編集、ゲームメモリの直接読み取り、外部ボット用プロトコルを使わない
- 既存ワールドを削除・上書きしない
- ユーザーの依頼なしにMOD、サーバー、データパックを導入しない

ポーズ、通常のゲーム設定、F3などMinecraftが提供する画面上の機能は利用できます。版や環境によってポーズの挙動が異なる場合は、実画面で確認します。

このルールに反しない限り、攻略順、戦術、観察間隔、操作の組み立て、分析方法、補助ツールの作成・改良はエージェントが選べます。
