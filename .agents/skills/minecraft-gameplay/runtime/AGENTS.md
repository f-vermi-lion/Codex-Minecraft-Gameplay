# Runtime safety invariants

このディレクトリの実装は変更・置換できます。ただし、ゲーム入力を送る経路は次の性質を保たなければなりません。

- 対象は、列挙・選択したMinecraftのHWNDとPIDの組だけである。
- 入力前と入力中に、対象が存在し、同じPIDで、前面かつ最小化されていないことを確認する。
- マウスボタン入力は、ポインターが対象Minecraftのクライアント内にあり、他ウィンドウに覆われていない場合だけ送る。
- F8、永続stop、フォーカス喪失で新規入力を止め、取得済みのキーとボタンを必ず解放する。
- watchdogは呼び出し側が停止・異常終了しても取得済み入力を解放する。
- mutexにより入力所有者を1つにする。
- テストは実ゲームやWin32入力を使わず、モックだけで実行できる。

高層の戦術、観察頻度、画像分析、操作列、時間配分はここで固定しません。変更後は `python -m unittest -q` を実行してください。
